# Persona-Based-AI-Assistant
An Intelligent Persona-Based Assistant for Shahid Motahari’s Intellectual System

این مخزن شامل کدهای پروژه با موضوع طراحی یک دستیار هوشمند (AI Agent) با محوریت منظومه فکری شهید مطهری است. در این پروژه با استفاده از معماری RAG، سیستمی طراحی شده که می‌تواند بدون پدیده توهم (Hallucination) به سوالات کاربران بر اساس کتاب‌های استاد مطهری پاسخ دهد و همچنین با کمک ابزار جستجوی وب، مسائل روز جامعه را تحلیل کند.

---

### ویژگی‌های اصلی پروژه
- **استخراج متن از کتاب‌های قدیمی:** به دلیل ناخوانا بودن فونت B Yagut در فایل‌های متنی، لایه متنی PDF به کل نادیده گرفته شد و استخراج متن با رندر تصویر از صفحات و استفاده از Tesseract OCR فارسی انجام شد.
- **چانک‌بندی جمله‌محور:** به جای برش متون با تعداد کاراکتر ثابت، متن‌ها بر اساس مرز جملات تقسیم شدند و تیترها به عنوان متادیتا ذخیره شدند تا استدلال‌های فلسفی ناقص نمانند.
- **بازیابی دو مرحله‌ای:** استفاده از فیلتر آستانه شباهت برای رد کردن سوالات بی‌ربط به کتاب، و انتخاب تعداد نتایج بر اساس نزدیکی امتیازات (به جای یک عدد ثابت).
- **تصمیم‌گیری عامل هوشمند:** اتصال مدل به ابزار جستجوی وب DuckDuckGo تا در صورت نیاز برای پدیده‌های بعد از شهادت استاد مطهری و مسائل روز جامعه در اینترنت جستجو کند.
- **پرامپت پرسونای دقیق:** مدل ملزم شده است تا بین نقل‌قول مستقیم از متن کتاب و برداشت تحلیلی خودش تفکیک قائل شود و حتماً آدرس صفحه و بخش کتاب را در انتهای پاسخ اعلام کند.

---

### ابزارها و کتابخانه‌ها
- **زبان برنامه‌نویسی:** Python
- **مدل زبانی:** Google Gemini API (gemini-3.1-flash-lite-
- **مدل امبدینگ:** BAAI/bge-m3
- **پایگاه داده برداری:** ChromaDB
- **کتابخانه‌های پردازش متن و تصویر:** PyTesseract
